# Gestion Stock Pharmacie

## Description
Ce projet est une application de gestion de stock d'une pharmacie développée avec Spring Boot.

L'application permet de gérer :
- Les produits
- Les catégories
- Les fournisseurs
- Les détails des produits
- Les tags

## Technologies utilisées

- Java 26
- Spring Boot 4.1.0
- Spring Data JPA
- Hibernate
- MySQL
- Thymeleaf
- HTML/CSS

## Architecture

Le projet est organisé selon une architecture en couches :

- Entity : gestion des entités JPA
- Repository : accès à la base de données
- Service : logique métier
- Controller : exposition des API REST et pages web

Nom de la base :
pharmacie
